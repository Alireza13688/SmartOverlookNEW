# Smart Overlook — همگام‌سازی وضعیت خروجی‌ها

این نسخه برای نمایش وضعیت واقعی ۸ خروجی در اپلیکیشن آماده شده است.

## تغییرات
- آردوینو پس از تغییر هر خروجی، پیام `STATE,<شماره>,ON` یا `STATE,<شماره>,OFF` می‌فرستد.
- اپلیکیشن پیام‌های `STATE` را می‌خواند و رنگ کارت همان خروجی را به‌روزرسانی می‌کند.
- پس از اتصال گوشی، اپلیکیشن فرمان `GET_STATE` می‌فرستد تا وضعیت فعلی هر ۸ خروجی را دریافت کند.
- لمس کارت و فرمان صوتی فقط فرمان می‌فرستند؛ رنگ کارت پس از دریافت تأیید وضعیت از آردوینو تغییر می‌کند.
- `ALL_OFF` باعث ارسال وضعیت خاموش برای هر ۸ خروجی می‌شود.

## اتصال‌ها
- HC-05 TXD به D10 آردوینو
- HC-05 RXD از D11 آردوینو با تقسیم ولتاژ مناسب
- خروجی‌های رله: D2 تا D9
- پل اول کلید فیزیکی: A0
- پل دوم کلید فیزیکی: A1

## توجه مهم
اسکچ Arduino داخل پوشه `SmartOverlook/arduino/SmartOverlook_UNO.ino` برای رله‌های Active LOW نوشته شده است:
`LOW = روشن` و `HIGH = خاموش`.

این پروژه بر اساس فایل منبع موجود بازبینی و تغییر داده شده، اما در این محیط امکان اجرای ساخت Gradle و آزمایش روی گوشی/برد واقعی فراهم نبود. قبل از جایگزین کردن نسخه قبلی، ابتدا کد آردوینو و سپس APK را آزمایش کنید.
