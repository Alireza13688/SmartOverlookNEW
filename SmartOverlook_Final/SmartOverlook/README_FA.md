# Smart Overlook — نسخه اولیه

پروژه اولیه اندروید برای کنترل Arduino UNO از طریق Bluetooth Classic و HC-05.

## قابلیت‌ها
- رابط فارسی و راست‌چین با تم سرمه‌ای/آبی
- انتخاب دستگاه جفت‌شده Bluetooth و اتصال RFCOMM
- تشخیص گفتار با زبان `fa-IR` از طریق سرویس گفتار نصب‌شده روی گوشی
- افزودن، ویرایش و حذف عبارت‌های صوتی
- نگاشت عبارت‌ها به ۸ خروجی یا خاموش‌کردن همه
- ذخیره دستورات در حافظه برنامه

## ساخت APK
1. Android Studio نسخه جدید را نصب کن.
2. پوشه `SmartOverlook` را با گزینه Open باز کن.
3. اجازه بده Gradle همگام‌سازی شود (این مرحله به اینترنت نیاز دارد).
4. از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کن.

حداقل Android 6.0 و هدف آزمایشی Android 14 API 34؛ روی Android 15 نیز اجرا می‌شود.

## راه‌اندازی HC-05
1. HC-05 را در تنظیمات بلوتوث گوشی Pair کن (PIN رایج بعضی ماژول‌ها 1234 یا 0000 است؛ برچسب/مستندات ماژول خودت را بررسی کن).
2. در برنامه «انتخاب و اتصال به HC-05» را بزن.
3. خروجی سریال HC-05 با 9600 baud تنظیم شده است.

## سیم‌کشی نمونه
- HC-05 TXD -> Arduino D10
- HC-05 RXD <- Arduino D11 از طریق تقسیم ولتاژ مناسب
- GND مشترک
- VCC فقط مطابق مشخصات برد HC-05 خودت؛ بسیاری از بردهای breakout ورودی 5V دارند، خود ماژول خام 3.3V است.
- خروجی‌های D2 تا D9

## پروتکل
فرمان‌ها باید با newline پایان یابند:
`OUT1_ON`, `OUT1_OFF`, ... `OUT8_ON`, `OUT8_OFF`, `ALL_OFF`

## نکات مهم و محدودیت‌ها
- تشخیص گفتار فارسی به سرویس تشخیص گفتار دستگاه/ارائه‌دهنده نصب‌شده، اینترنت و پشتیبانی `fa-IR` وابسته است؛ این برنامه خودش موتور گفتار ابری اختصاصی ندارد. عملکرد را روی گوشی واقعی آزمایش کن.
- HC-05 با Bluetooth Classic SPP کار می‌کند؛ برای گوشی‌های جدید باید از صفحه تنظیمات سیستم Pair شده باشد و مجوز Nearby devices/Bluetooth Connect داده شود.
- برای آزمایش، خروجی‌های UNO را فقط با LED و مقاومت مناسب بررسی کن. برای رله و بارهای واقعی از مدار درایور ایزوله و حفاظت‌شده استفاده کن؛ برق شهر را مستقیم به بردبورد/UNO وصل نکن.
- این نسخه پایه است و هنوز APK امضاشده/منتشرشده نیست. فایل پروژه را در Android Studio بساز و ابتدا روی سخت‌افزار واقعی آزمایش کن.
